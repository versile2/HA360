# Changelog

## 0.1.0

First experimental release.

- Map-first family locator inside Home Assistant (Ingress sidebar panel): live positions, a bottom sheet with
  Drivers, Vehicles and Places, and a weekly Driving report.
- Live positions come from Home Assistant's own entities; the app keeps its own SQLite history under `/data`.
- Demo mode shows a fictional family, so an install can be checked without any real data.
